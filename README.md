# Analyse des facteurs de risque du diabète 🏥
## Source des données
- **Dataset** : Diabetes Health Indicators Dataset
- **Source** : Kaggle — [lien vers le dataset](https://www.kaggle.com/datasets/alexteboul/diabetes-health-indicators-dataset)
- **Origine** : Behavioral Risk Factor Surveillance System (BRFSS) — CDC américain
- **Taille** : 253 680 observations, 22 variables
- **Licence** : Publique

## À propos
Analyse exploratoire d'un dataset de 253 680 patients américains 
pour identifier les facteurs de risque associés au diabète de type 2.

## Outils utilisés
- Python (Pandas, NumPy, Plotly)
- Jupyter Notebook

## Principaux insights
- Les diabétiques ont un BMI moyen 4 points supérieur aux non diabétiques
- Le taux de diabète passe de 2% chez les jeunes à 20% chez les 70+
- Les maladies cardiaques sont 3x plus fréquentes chez les diabétiques
